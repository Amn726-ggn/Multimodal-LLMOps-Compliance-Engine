# Multimodal LLMOps Compliance Engine

An AI-powered compliance audit pipeline for analyzing video content and producing compliance results.

## Requirements

- Python 3.12 or newer
- Azure and other service credentials configured locally

## Setup

1. Create and activate a virtual environment.
2. Install dependencies with `uv sync` or `pip install -e .`.
3. Copy the required settings into a local `.env` file.
4. Run the application with the entry point appropriate for your workflow.

The `.env` file is intentionally ignored by Git. Never commit API keys, connection strings, or other credentials.
